Suggested default: B float on first Home after the first primary rotation is saved.

  • Trigger: periods just went 0→1 primary (or preference postFirstRotationCoachSeen === false and exactly one primary exists).
  • Compartir → system share sheet with the new period’s link (same as detail).
  • Widget → how-to sheet (B1b); no OS add-widget API.
  • Ahora no / any successful action → set preference, never show again.
  • Skip coach when the first save came from a shared-link deep link (they already know sharing).
