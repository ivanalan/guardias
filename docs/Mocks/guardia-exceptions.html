Day sheet states

Product rules baked into this mock

  1. Instant toggle — no confirm dialog for single-day edits.
  2. Cover days: same shift fill + dashed edge / corner mark. Skipped: empty (optional faint strike in demo).
  3. Legend: one extra line (“Edited days”) — not three new chips.
  4. Friend secondary dots: open day sheet read-only for their schedule; no skip/cover.
  5. Copy uses resident verbs — never “exception / override / EXDATE”.
