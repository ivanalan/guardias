Recommendation: B, and steal D's divider. The pills read as dated for three reasons that a restyle alone doesn't fix: the thick colored stroke is the 2017-era Material filter chip, variable-width pills wrap into a ragged tag cloud as soon as a rotation has a real name, and nothing signals that a legend is also a filter.

  1. B (color-key rows) — the token is the mark from the grid, so the legend teaches the color code instead of restating it in a border. Fixed one-per-line layout means a long rotation name truncates instead of reflowing the block. Selection moves into the token (filled vs hollow) so unselected rows read as "not focused" rather than disabled, and Show all gives the filtered state an exit.
  2. D is B docked inside the white card under a hairline. It stops the legend from floating in the cream background and makes it feel like part of the calendar. Cheap to add on top of B.
  3. C is the option if you want to keep chip shapes: no colored stroke, tint fill for selection, horizontal scroll so it never wraps. A visual refresh, not a better legend.

None of these touch the filter logic in build-marked-dates.ts or the dimming in calendar-day.tsx — the change is confined to calendar-month-legend.tsx plus a few i18n keys (count split out of the label, new Show all / Mostrar todo).
